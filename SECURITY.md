# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The voltdex project takes security seriously. If you discover a vulnerability or security flaw (such as path traversal, unintended network access, or denial-of-service risks), please report it responsibly.

### How to report

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Please report security advisories via the **Security** tab of this repository under **Advisories** -> **Report a vulnerability**. This allows us to discuss and resolve the issue privately before a public disclosure.

2. **Email**:
   If private vulnerability reporting is unavailable, you can contact the maintainer directly at the email listed on their [GitHub Profile](https://github.com/cain19811028).

**Please do not report security vulnerabilities through public GitHub issues.**

### What to expect

- **Acknowledgement**: You will receive an initial response within 48 hours acknowledging receipt of your report.
- **Assessment**: We will evaluate the impact and coordinate a timeline for releasing a fix.
- **Credit**: If desired, we will credit your contribution in the release notes and advisory when the patch is published.
